# Website Admin — Quick Guide

Everything you can change on the website is edited at **yourwebsite.com/admin**.
Nothing you do there can break the design.

## Signing in
1. Go to `/admin`.
2. Enter the **username** and **password** your administrator gave you, then click **Sign In**.
3. You land on the **Dashboard** — big cards for each part of the website.
4. When you finish, click **Log out** (top right of the Dashboard). You are also signed out automatically after 8 hours.

> **Important:** this admin uses one shared account. Anyone who has the username and password can change the website. Do not share them outside your team, and ask your administrator to change the password when someone leaves.

## The basic routine (always the same)
**Open → Change → Preview → Publish**

1. Click a card on the Dashboard (or use the menu on the left).
2. Change the text or image.
3. Click the **Preview** tab at the top to see your change on the real website.
4. Go back and click the green **Publish** button. The website updates in a few seconds.

Your changes are saved automatically as a draft. Nothing goes live until you click **Publish**.

## Change the homepage heading
1. Dashboard → **Homepage**.
2. Open the **Hero (top)** tab.
3. Edit the three headline lines.
4. Preview, then **Publish**.

## Change any text or image on the homepage
Homepage has one tab per section: *Hero, Who We Are, Leadership, Strategic Capabilities, Industry Sectors, Markets, Philosophy quote, Contact.*
Open the tab, edit, Publish.

## Replace a picture
Click the image → **Upload** (or drag a new file in). Always fill in **Describe this image** — it helps people using screen readers and Google.

## Hide a section
In its tab, switch **Show this section** off, then Publish. Turn it on again any time.

## Reorder things
Wherever you see a list (leadership, capabilities, sectors, menu links, regions) **drag the handle** on the left of an item up or down, then Publish.

## Add a team member
1. Dashboard → **Leadership** → **+ Create**.
2. Fill in name, job title and short introduction. Click **Generate** next to the web address.
3. Add the biography (use **Section heading** for the titles). Add LinkedIn if you have it.
4. **Publish**.
5. Open **Homepage → Leadership** and add the person to the list (drag to choose the position). Publish.

## Hide or remove a team member
Switch **Show on website** off and Publish — or use the delete option (you will be asked to confirm).

## Edit capabilities or industry sectors
Dashboard → **Strategic Capabilities** / **Industry Sectors** → open one → edit → Publish.
To add a new one: **+ Create**, then add it to the list in **Homepage → Strategic Capabilities** (or **Industry Sectors**).

## Change the menu
Left menu → **Website → Menu**. Edit link text, choose where each link goes from the list, drag to reorder, Publish.

## Change contact details or social links
Dashboard → **Website Settings**. Social links only appear on the website if you fill them in.

## Search engines (Google)
Homepage → **Search & sharing** tab, and Website Settings → **Search & sharing**.
- *Search title* is the blue headline in Google.
- *Search description* is the grey text under it.

## If something looks wrong
- A red or yellow message next to a field tells you what is missing (for example “Please add the button text before publishing”). Fix it and Publish again.
- Made a mistake after publishing? Open the item → click the **⋯** menu → **Review changes / History** and restore an earlier version.
